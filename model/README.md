# 可变后掠翼机构三维模型

**Variable-Sweep-Wing Mechanism — SolidWorks Models**

本目录存放可变后掠翼机构的 SolidWorks 三维设计文件，包括机构总装配体、零件模型、齿轮配合辅助装配体及工程图。模型涉及机架、后掠翼、曲柄—连杆—摇杆相关构件，以及齿轮、蜗轮与蜗杆等传动零件，供机构结构查看、设计修改和后续运动分析使用。

> **说明：** 本目录提供的是 CAD 设计文件。仅凭现有文件清单和装配树，尚不能确认装配配合、机构运动、传动参数或工程图已完成验证；具体以 SolidWorks 中的实际模型及检查结果为准。

## 3. 装配体结构

从 `可变后掠翼机构.SLDASM` 的设计树可以看到：

- `机架（支座）` 在主装配体中显示为固定零件。
- 机构包含后掠翼、翼根连接件、曲柄、连杆、摇杆及相应铰接件。
- 传动相关零件包括曲柄传动轴、齿轮、大齿轮、蜗杆、蜗轮和蜗轮齿轮连接件。
- 部分零件在装配体中存在多个实例，例如机翼连接铰和部分传动零件。装配树中的实例编号并不对应独立的零件文件。
- 主装配体中包含配合特征和草图；配合是否完整、运动是否无干涉，仍需在 SolidWorks 中进一步检查。

## 4. 打开与使用

1. 下载或克隆完整仓库，**保留 `model/` 内全部原始文件名**。
2. 使用支持这些文件版本的 **SOLIDWORKS** 打开 `可变后掠翼机构.SLDASM`。
3. 如出现缺失零部件提示，优先检查同目录下的 `.SLDPRT` 文件并重新定位引用。
4. 在装配体中检查零件是否全部加载、配合是否报错，以及机构是否存在干涉。
5. 如需查看工程图，打开 `可变后掠翼机构.SLDDRW`；如需研究齿轮配合，单独打开 `齿轮配合.SLDASM`。

**兼容性：** SOLIDWORKS 文件通常无法直接使用较旧的软件版本打开由较新版本保存的文件。本项目的创建软件版本尚未在本 README 中标明。

## 5. 使用注意事项

- `.SLDASM` 和 `.SLDDRW` 可能引用其他零件文件；请勿只下载主装配体或随意更改文件名、目录层级。
- “参数化设计”文件与同名常规零件可能存在不同设计状态，请在修改前确认主装配体的实际引用关系。
- 当前 README **不声明**已完成运动学仿真、干涉检查、强度校核、加工制造或实物验证。
- 如果后续发布 STEP 文件、运动演示、尺寸参数、传动比和验证结果，可在仓库中补充对应说明。

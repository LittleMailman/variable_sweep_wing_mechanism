# 04 可变后掠翼技术文献综述

## 1. 研究范围

可变后掠翼（Variable-Sweep Wing）通过改变机翼相对于机身的后掠角，调整飞行器的平面几何外形，以适应不同的飞行状态或任务要求。它属于变体机翼（Morphing Wing）的平面外形变化范畴，与变翼展、变弦长、变弯度、机翼扭转等技术存在联系，但机构形式和设计约束并不相同。[1]

本综述以本项目已有设计资料中的**研究背景、研究现状、机构选型与参考文献**为基础，围绕以下问题组织：可变后掠翼为何需要专门的机械驱动系统、典型机构方案如何实现运动、以及面向中小型飞行器时需要兼顾哪些工程约束。另补充了可公开核查的变体飞行器综述、可变后掠翼技术综述和复合连杆机构研究文献。

本文属于**与本仓库机械设计直接相关的主题综述**，不宣称覆盖截至目前全部最新研究；本项目也未完成气动试验或实飞验证。

## 2. 可变后掠翼的研究背景

### 2.1 气动外形与任务条件的适配

固定机翼的平面形状需要兼顾不同飞行速度、升力需求和结构条件。后掠角变化能够改变机翼外形的气动特征；在不同速度区间，适当的后掠角可能有利于协调低速升力需求与高速压缩性影响，但实际性能改善依赖具体翼型、展弦比、马赫数、结构和控制条件，不能仅凭后掠角变化就断言升阻比一定提高。[1][2]

本项目采用的 **15°、45°、75°** 是机械设计目标中的典型后掠角状态，而不是经风洞试验或 CFD 确认的最佳气动角度。**3 m 完全展开翼展**同样属于总体设计目标，不能作为已制造样机的测量结果。

### 2.2 机械系统带来的额外约束

相比固定翼，变后掠翼需要翼根旋转支承、传力构件、驱动器以及必要的保持或锁紧措施。后掠过程中，气动力作用点、翼根力矩以及左右翼几何关系可能随运动改变。这意味着不能只优化运动行程，还需要同时考虑：

- **质量与空间占用：** 驱动器、传动轮系及支承结构占据机身空间，并增加重量。
- **左右翼协调：** 两侧翼根应按设计规律运动，不能以共用驱动器代替同步误差验证。
- **承载与可靠性：** 铰点反力、翼根力矩、间隙及极限位置的保持能力需要校核。
- **变形与飞行的耦合：** 机械上能够改变后掠角，并不代表变形过程中飞行器仍满足稳定性与操纵要求。

Barbarino 等在变体飞机综述中将驱动系统的附加重量和工程成熟度列为实现机翼变形的重要限制因素。[1]

## 3. 技术发展与研究方向

### 3.1 传统变后掠翼与变体飞行器

可变后掠翼从早期的机械枢轴结构发展到具有复杂传动与控制系统的飞机应用。F-111、F-14、MiG-23 和 Tornado 等机型说明该概念具有工程应用基础，但大型飞机的设计经验不能直接等同于中小型无人机的最佳机构方案。[2]

变体飞行器研究随后从单一后掠角变化扩展为机翼平面形状、翼型与结构的协同改变。[1] 对本项目而言，研究重点不是实现全功能变体机翼，而是先明确**可变后掠运动如何由有限数量的机械构件可靠实现**。

### 3.2 机械实现路径

项目设计资料重点比较了以下三类机构：

| 机构类型 | 主要运动转换 | 典型研究关注点 |
| --- | --- | --- |
| 丝杠滑块机构 | 电机旋转 → 丝杠直线运动 → 翼根转动 | 导轨布置、行程与左右同步 |
| 转动导杆机构 | 推杆/滑块运动 → 导杆转动 → 翼根转动 | 推杆行程、两侧驱动协调与运动约束 |
| 曲柄摇杆机构 | 曲柄旋转 → 连杆传力 → 摇杆摆动 | 尺寸综合、输出摆角、死点及机构干涉 |

这三种类型均可构成可变后掠运动机构，但驱动方式、质量、安装空间和位置约束不同；**目前缺少基于同一载荷、质量与几何边界的定量对比试验**。详细选型过程见 [05 结构方案比较与选择](05_mechanism_selection.md)。

作为相关先例，Toms 的变后掠翼专利涉及通过移动支点与导向机构调整机翼后掠，以处理翼根位置随变形改变的问题。[4] Arena 的分段变后掠翼专利则采用分段机翼联动改变后掠状态，体现了另一类机械方案。[5] 这两项专利仅作为机构构型参考，不代表本项目直接复现了其具体结构。

### 3.3 机构尺寸综合与运动可行性

可变后掠翼机构的核心机械问题之一，是在有限安装空间内使输入转动转化为期望的翼根运动，同时避免不可装配、极限死点和错误的装配分支。

都显琛等提出基于平面复合连杆机构的变后掠翼联动驱动设计，将机构划分为子机构，通过矢量环路方程分析可动性，并结合优化方法处理尺寸综合和运动到位问题。[3] 这一研究说明**运动可行性、包络空间和设计位置应当共同考虑**，不能仅凭少量目标角度就证明整个运动行程有效。

本项目现有 MATLAB 程序包含杆长综合、传动角、双侧运动学及摇杆响应计算，但其输出仍需要与 SolidWorks 实际铰点、装配分支、零位和翼根后掠角建立一致的映射关系。

### 3.4 动力学、驱动与保持机构

单侧平面四杆机构可以作为关节反力和曲柄驱动力矩的初步分析模型，但完整双侧机构还涉及两侧负载如何在中央驱动轴上汇合，以及齿轮效率、摩擦、结构变形等因素。

特别需要区分：

1. **几何死点或极限位置**不等于已经具备外载荷下的安全锁紧能力。
2. **蜗轮蜗杆具有较大减速比**不等于可以在任意导程角、摩擦条件下保证自锁。
3. **MATLAB 示例力矩曲线**不等于经过实际质量、惯量和气动力校核的电机选型载荷。

因此，针对本仓库的研究资料，运动学曲线宜作为**模型计算示例**展示，动力学结果须连同计算工况和未校准参数一起说明。

## 4. 对本项目机械设计的启示

结合上述文献与已有机构资料，可形成以下设计认识：

- **结构形式优先服务于运动目标：** 先确认翼根转轴、后掠角行程、安装空间及左右翼关联关系，再比较不同机构。
- **单驱动有利于减小独立执行器数量：** 但并不天然保证左右摇杆输出完全对称，必须通过机构几何和装配校核确定。
- **连杆尺寸与弧形构件形状分别解决不同问题：** 前者决定理论运动关系，后者可为实体构件提供避让空间，二者均需验证。
- **极限位置应单独开展保持能力分析：** 不能将死点、蜗杆传动或摩擦直接视作可靠锁紧的实验证据。
- **结果应分层验证：** MATLAB 运动学 → CAD 机构运动 → 真实质量与载荷 → 结构和实体实验；本仓库现阶段主要覆盖前两类资料的建模与展示，其中一致性复核仍待完成。

上述结论用于解释本项目**为何选择曲柄摇杆与集中式齿轮传动**，而不是宣称该方案在所有飞行器或任务中均优于其他机构。

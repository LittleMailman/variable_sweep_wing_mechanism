# 技术文档 | Documentation

本目录为可变后掠翼机构开源项目的设计与计算资料，采用 **3 份报告**组织。资料基于原《一种可变后掠翼的机构设计》课程设计说明书（2022 年）与后续整理的 SolidWorks、MATLAB 文件。

| 报告 | 内容 | 阅读建议 |
| --- | --- | --- |
| [01 机构设计报告](01_mechanism_design.md) | 设计目标、方案选型、结构组成、传动与 CAD | 先了解机构如何工作 |
| [02 运动学分析报告](02_kinematics_analysis.md) | 尺寸综合、压力角/传动角、绝对和相对运动、双侧摇杆角 | 对照 MATLAB 曲线阅读 |
| [03 动力学分析报告](03_dynamics_analysis.md) | 受力图、运动反力、动态静力计算、结果及待核对参数 | 了解受力计算的适用边界 |

其他目录：[三维模型](../model/) · [MATLAB 代码](../code/) · [仿真结果](../results/) · [运动视频](../results/videos/)。

**当前状态：** 已提供设计模型、计算脚本及相应图像，部分程序已在 MATLAB 中运行并绘图；尚未完成 CAD 与数学模型的一致性复核、真实载荷验证、样机制造、试飞或气动实验。因此文中的尺寸、传动比、力矩均应结合对应版本和工况理解，不可直接作为工程选型结论。

> 公开说明：本目录未包含原课程说明书全文，也未包含其中的个人信息及引用的第三方文献图片；引用原始资料时应核对来源和授权。

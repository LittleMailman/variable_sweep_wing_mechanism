# 05 可变后掠翼机构方案比较与结构选择

## 1. 设计目标与机构选择原则

本项目研究通过机械机构改变左右机翼的后掠角。设计资料提出的总体目标为**完全展开翼展 3 m**，典型后掠角分别为 **15°、45° 和 75°**。上述数据属于机械设计目标；当前仓库尚未提供逐点实测的机翼后掠角、真实气动载荷或实体样机。

对于这一任务，机构选型需要回答三个问题：

1. 如何在机身内部有限的空间中，将执行器运动转换为两侧翼根转动？
2. 如何使两侧机翼按照预定几何关系运动，并控制不同步误差？
3. 如何在运动极限位置承受翼根载荷，并避免构件干涉或驱动系统反向运动？

本项目采用**机构布局、运动传递、左右同步、承载与锁止、制造维护复杂性**作为定性比较指标。由于缺乏三种候选方案在统一约束和载荷下的质量、效率、可靠性及成本数据，以下比较不采用主观的量化评分，也不宣称某种机构具有普适最优性。

## 2. 候选方案分析

### 2.1 丝杠滑块机构

丝杠滑块机构利用电机驱动丝杠旋转，通过丝杠螺母带动滑块沿导轨平移，再经连杆或转动副推动机翼翼根绕轴转动。

**主要特点：**

- 直线行程和滑块位置之间具有明确的运动关系，便于建立翼根角度映射。
- 执行器可布置于机身内部，但需要预留丝杠轴向空间、导轨安装空间与行程端部余量。
- 左右翼若分别使用丝杠或滑块，则必须明确机械联动方式或双驱同步控制方式。
- 丝杠、螺母、导轨和连接杆件带来额外的安装、配合及维护要求。

**适用条件：** 机身允许布置直线行程，且优先考虑可预测的直线输入与位置控制时，该方案值得考虑。

**本项目的局限：** 在当前机械布局中，丝杠及导轨的空间占用和双侧协调增加了布置难度，因而未作为主体方案。

相关结构可参考文献综述中的变后掠翼机构专利与设计资料：[04 文献综述](04_literature_review.md)。

### 2.2 转动导杆机构

转动导杆机构以气缸、电动推杆或滑块为驱动元件，沿导杆或滑槽产生相对运动，带动与翼根相关的构件转动。

**主要特点：**

- 可以把直线执行器的伸缩行程转换为机翼后掠转角。
- 摆角范围由杆件长度、导向布置、滑块行程及安装位置共同决定。
- 双侧机翼采用独立推杆时，同步性取决于传动耦合或控制协调，而非机构名称本身。
- 需要检查导向副侧向载荷、传动角变化、杆件空间避让与极限位置承载能力。

**适用条件：** 已有推杆布置空间、需要直线驱动或计划扩展分段翼面联动时，可作为候选机构。

**本项目的局限：** 当前方案更侧重单一中央动力输入和机械联动，转动导杆方案需要额外确定左右侧的协调结构。

### 2.3 曲柄摇杆机构

曲柄摇杆机构通过曲柄转动，带动连杆推动摇杆摆动。若机翼与摇杆建立刚性连接，则摇杆的几何运动可转换为翼根的后掠角变化。

本项目采用**中央曲柄、左右连杆与翼根摇杆**组成的机构布局，由同一传动链提供动力。

**主要特点：**

- 主要运动由转动副和连杆完成，易于使用平面四杆模型分析。
- 单个中央驱动构件可以同时驱动两侧连杆，减少独立执行器数量。
- 摇杆摆角、运动速度和传动角受杆长、安装铰点与初始相位制约，可以通过尺寸综合进行设计。
- 左右翼存在装配分支、几何镜像和相位差问题；共用曲柄**不保证两侧实际输出角度完全相同**。
- 极限位置可能接近死点或低传动角区域，需额外研究驱动力矩、承载和可靠保持条件。

**适用条件：** 以机械联动为主、重视结构紧凑和数学模型可分析性，并接受后续进行杆长及装配构型校核时，该方案具有吸引力。

## 3. 方案比较

| 比较维度 | 丝杠滑块 | 转动导杆 | 曲柄摇杆（本项目） |
| --- | --- | --- | --- |
| 主要输入 | 丝杠旋转形成直线行程 | 推杆或滑块行程 | 曲柄旋转 |
| 输出方式 | 滑块经连杆驱动翼根 | 导杆或滑槽带动翼根 | 连杆推动翼根摇杆 |
| 机构布局 | 需导轨与丝杠行程 | 需推杆及导向空间 | 主要由转动副和连杆构成 |
| 双侧协调 | 可机械联动或双侧执行器协调 | 需设计双侧同步机制 | 共用曲柄输入，但输出同步仍需几何验证 |
| 运动范围控制 | 主要受行程和安装几何限制 | 主要受导杆和推杆几何限制 | 主要受杆长、相位及装配分支限制 |
| 主要校核事项 | 导轨、丝杠与传动间隙 | 导向副受力及行程端点 | 传动角、死点、干涉及铰点载荷 |
| 选型评价 | 可作为直线驱动备选 | 可作为推杆驱动备选 | 与本项目集中驱动布局匹配 |

此表基于**运动学构成和机构布局**进行定性比较，不是统一试验工况下的性能排名。

## 4. 本项目的最终机械方案

### 4.1 选择结果

综合机身内部布局、执行器数量、两侧机械联动和分析方法，本项目选择：

**蜗轮蜗杆与齿轮轮系减速 + 中央曲柄 + 左右连杆 + 两侧翼根摇杆**。

运动传递路径：

\`\`\`text
电机 / 蜗杆输入
      ↓
蜗轮及齿轮轮系
      ↓
中央曲柄转动
      ├── 左侧连杆 → 左侧翼根摇杆 → 左翼后掠
      └── 右侧连杆 → 右侧翼根摇杆 → 右翼后掠
\`\`\`

### 4.2 结构组成与设计意图

**中央曲柄：** 将齿轮传动的转动输出输入双侧连杆系统。其安装位置、曲柄夹角及回转空间影响左右侧机构的运动关系。

**弧形连杆：** 在实现铰点间几何连接的同时，为曲柄、翼根以及其他构件提供空间避让。弧形轮廓不改变以两端铰点中心距定义的平面四杆几何模型，但可能影响质量分布、刚度和构件实际干涉。

**翼根摇杆与转轴：** 将连杆输出转换为翼根转动；实际翼根后掠角必须通过机翼连接关系、坐标基准及镜像方向建立映射。

**蜗轮蜗杆与齿轮轮系：** 用于动力传递与减速，并调整驱动轴的安装方向。蜗杆能否可靠防止反驱需要结合传动副几何、摩擦及外部载荷核查，不能把减速直接视为自锁证明。

## 6. 极限位置、同步与锁紧问题

### 6.1 极限位置与传动角

曲柄摇杆机构在接近特殊几何位置时可能出现传动角降低、驱动力矩敏感或位置控制困难。后掠角到达设计极限位置并不自动说明机构处于可靠的静态锁止状态。

### 6.2 两侧协调

两侧由同一中央曲柄驱动，具有共同的输入角度与传动链，但其输出角度是否同步取决于两侧铰点位置、对称关系、曲柄相位以及装配分支。因此，不能仅凭“单电机驱动两侧”便认为已经消除了同步误差。

### 6.3 载荷保持

翼根可能承受变化的外部载荷，既可能通过连杆与齿轮级反作用于输入轴，也可能引起构件变形或配合间隙。自锁或保持性能尚需依据真实载荷、传动副与锁紧机构设计进行单独验算。

## 7. 选型结论与适用边界

在当前设计目标下，曲柄摇杆机构与集中式传动系统能够在结构形式和运动分析方法上形成较直接的工程方案。选择它的主要理由是：

1. 单个中央驱动输入可以机械连接两侧连杆机构。
2. 杆长、相位及几何闭合关系可以使用四杆机构数学模型开展分析。
3. 弧形连杆等实体构件允许在 CAD 中进一步处理运动干涉问题。
4. 蜗轮蜗杆与齿轮轮系为电机安装和减速布置提供了可行方式。

**本项目已完成机构方案、CAD 模型、MATLAB 示例计算和运动演示资料的归档；尚未证明该方案在质量、效率、承载能力或可靠性方面优于所有替代方案。**

有关动力学计算条件、质量与转动惯量差异，以及输出结果的限制，参见 [03 动力学分析报告](03_dynamics_analysis.md)。

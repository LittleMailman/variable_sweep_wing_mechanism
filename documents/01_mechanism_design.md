# 01 可变后掠翼机构设计报告

## 1. 项目定位与设计目标

本项目研究一种通过机械传动改变左右机翼后掠角的机构。原课程设计以中型可变后掠翼无人机作为概念背景，侧重**机构设计与运动仿真**，并非已经制造和验证的整机。

| 项目 | 历史设计目标/条件 | 解释 |
| --- | --- | --- |
| 完全展开翼展 | 3 m | 原报告的概念目标，非实测参数 |
| 典型后掠角 | 15°、45°、75° | 方案目标，尚未以当前 CAD 逐点核对 |
| 传动方式 | 蜗轮蜗杆 + 齿轮轮系 + 曲柄摇杆 | 已有 CAD 模型与动画演示 |
| 左右机翼运动 | 同一驱动链带动两侧翼根转动 | 仍需核查实际同步误差 |

设计关注机翼转角范围、左右翼同步、机构干涉、驱动布置和零部件受力，而不是气动特性、飞控性能或实飞性能。

## 2. 机构方案比较

原说明书讨论了丝杠滑块、转动导杆和曲柄摇杆三种机械实现方案：

| 备选方案 | 运动转换 | 主要设计考虑 |
| --- | --- | --- |
| 丝杠滑块机构 | 旋转输入 → 直线位移 → 机翼转动 | 直线传动空间、滑动副及双侧协调 |
| 转动导杆机构 | 作动器 → 导杆/滑块 → 机翼转动 | 导向约束、行程及两侧同步 |
| 曲柄摇杆机构 | 曲柄旋转 → 连杆传动 → 摇杆摆动 | 摆角、相位差、构件干涉与极限位置 |

在原课程设计中选用**曲柄摇杆机构**作为主体方案。该选择是针对当时设计目标的工程取舍，不代表三种方案已经完成同工况、同尺寸的定量性能对比。

## 3. 机械系统组成及运动原理

机构可分为固定支撑、连杆变后掠机构和动力传动轮系三个部分。

| 组成部分 | 主要构件 | 作用 |
| --- | --- | --- |
| 固定结构 | 机架、支座、转轴及连接件 | 为驱动机构及翼根转轴提供支撑 |
| 连杆机构 | 中央曲柄、左右连杆、摇杆及机翼连接件 | 将曲柄连续转动转换为机翼后掠角变化 |
| 传动机构 | 蜗杆、蜗轮、大/小齿轮等 | 降速并将驱动输入传递至曲柄 |

**传动路径：**

```text
蜗杆（动力输入）
  → 蜗轮
  → 齿轮轮系
  → 中央曲柄
  → 左右连杆
  → 两侧摇杆与翼根
  → 机翼后掠角变化
```

曲柄与连杆采用避让干涉的形状设计；原课程说明书中提出使用弧形连杆，以减小运动过程中的构件碰撞风险。曲柄两侧通过几何连接共同驱动，但左右翼角度是否完全同步仍取决于机构尺寸、角度基准和装配分支。

原报告还讨论了极限位置接近死点、以及蜗轮蜗杆可能具有保持作用的设计思路。**目前没有充分证据证明在外载荷下具备可靠自锁能力**，需要进一步验证蜗杆导程角、摩擦系数、机构约束和负载。

## 4. 齿轮与蜗轮蜗杆传动参数

历史说明书中记录如下示例参数：

| 传动件 | 历史记录 |
| --- | ---: |
| 蜗杆头数 | 1 |
| 蜗轮齿数 | 40 |
| 小齿轮齿数 | 24 |
| 大齿轮齿数 | 28 |
| 标称总传动比 | 80（原报告记载） |
| 运动视频中的蜗杆输入转速 | **200 RPM** |

原报告将总传动比写为 80，而根据所列 1 头蜗杆、40 齿蜗轮及 24/28 齿的单级齿轮副推算，仅两级传动比约为 \(40\times 28/24\approx46.67\)。二者**不一致**，需要核对实际传动级数、啮合配置及参数记录。因此视频的 200 RPM 只是蜗杆输入设定，不等于曲柄或翼根转速；原报告提出的约 12.1 s 展收时间亦应视作历史估算。

## 6. 尚待核对的机械设计事项

- 实际 CAD 中的曲柄—连杆—摇杆铰点中心距，以及机架安装尺寸；
- 两侧曲柄夹角和机翼后掠角在同一坐标系下的零位定义；
- 真实蜗轮蜗杆头数、齿轮齿数、传动链及传动比；
- 曲柄、弧形连杆、翼根与传动件的干涉和极限位置；
- 机翼载荷作用时是否需要独立锁紧装置。

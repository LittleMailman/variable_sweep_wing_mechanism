# 01 可变后掠翼机构设计报告

## 1. 项目定位与设计目标

本项目面向无人机可变后掠翼机械系统，研究通过集中式机械传动驱动左右机翼改变后掠角的实现方法，涵盖**机构方案、传动系统、三维建模与运动仿真**。目前公开的成果为设计模型与分析资料，不包含已完成实物验证的飞行平台。

| 项目 | 设计指标 / 分析条件 | 说明 |
| --- | --- | --- |
| 完全展开翼展 | 3 m | 总体设计指标，未进行实物测量 |
| 典型后掠角 | 15°、45°、75° | 方案目标，尚未以当前 CAD 逐点核对 |
| 传动方式 | 蜗轮蜗杆 + 齿轮轮系 + 曲柄摇杆 | 已有 CAD 模型与动画演示 |
| 左右机翼运动 | 同一驱动链带动两侧翼根转动 | 仍需核查实际同步误差 |

本阶段重点研究后掠角范围、左右翼同步、运动干涉、驱动布置及零部件受力。气动性能、飞行控制与飞行验证不属于当前成果的验证范围。

## 2. 机构方案比较

机构方案评估考虑了丝杠滑块、转动导杆和曲柄摇杆三种机械实现形式：

| 备选方案 | 运动转换 | 主要设计考虑 |
| --- | --- | --- |
| 丝杠滑块机构 | 旋转输入 → 直线位移 → 机翼转动 | 直线传动空间、滑动副及双侧协调 |
| 转动导杆机构 | 作动器 → 导杆/滑块 → 机翼转动 | 导向约束、行程及两侧同步 |
| 曲柄摇杆机构 | 曲柄旋转 → 连杆传动 → 摇杆摆动 | 摆角、相位差、构件干涉与极限位置 |

本项目采用**曲柄摇杆机构**作为主体变后掠机构。这一选择基于机械布局和运动形式的综合考虑，尚未开展三种方案在统一工况与尺寸约束下的定量性能对比。

## 3. 机械系统组成及运动原理

机构可分为固定支撑、连杆变后掠机构和动力传动轮系三个部分。

| 组成部分 | 主要构件 | 作用 |
| --- | --- | --- |
| 固定结构 | 机架、支座、转轴及连接件 | 为驱动机构及翼根转轴提供支撑 |
| 连杆机构 | 中央曲柄、左右连杆、摇杆及机翼连接件 | 将曲柄连续转动转换为机翼后掠角变化 |
| 传动机构 | 蜗杆、蜗轮、大/小齿轮等 | 降速并将驱动输入传递至曲柄 |

**传动路径：**

```text
蜗杆（动力输入）
  → 蜗轮
  → 齿轮轮系
  → 中央曲柄
  → 左右连杆
  → 两侧摇杆与翼根
  → 机翼后掠角变化
```

曲柄与连杆采用避让干涉的形状设计，其中弧形连杆用于减小运动过程中的构件碰撞风险。曲柄两侧通过几何连接共同驱动，但左右翼角度是否完全同步仍取决于机构尺寸、角度基准和装配分支。

机构设计考虑了极限位置接近死点，以及蜗轮蜗杆可能产生的运动保持作用。**目前没有充分证据证明在外载荷下具备可靠自锁能力**，需要进一步验证蜗杆导程角、摩擦系数、机构约束和负载。

## 4. 齿轮与蜗轮蜗杆传动参数

传动系统采用的参数记录如下，具体齿数和啮合关系仍需与 CAD 装配体核对：

| 传动件 | 参数 |
| --- | ---: |
| 蜗杆头数 | 1 |
| 蜗轮齿数 | 40 |
| 小齿轮齿数 | 24 |
| 大齿轮齿数 | 28 |
| 标称总传动比 | 80（待核对） |
| 运动视频中的蜗杆输入转速 | **200 RPM** |

当前参数表给出的标称总传动比为 80；若传动链仅由 1 头蜗杆与 40 齿蜗轮、以及 24 齿主动齿轮与 28 齿从动齿轮构成，理想传动比为：

```math
i=40\times\frac{28}{24}\approx46.67
```

两者**不一致**，需要依据 CAD 确认传动级数、动力流和实际啮合配置。视频中的 200 RPM 是蜗杆输入转速设定，并非曲柄或翼根转速；约 12.1 s 的展收时间仅作为计算参考，尚未独立验证。

- 实际 CAD 中的曲柄—连杆—摇杆铰点中心距，以及机架安装尺寸；
- 两侧曲柄夹角和机翼后掠角在同一坐标系下的零位定义；
- 真实蜗轮蜗杆头数、齿轮齿数、传动链及传动比；
- 曲柄、弧形连杆、翼根与传动件的干涉和极限位置；
- 机翼载荷作用时是否需要独立锁紧装置。

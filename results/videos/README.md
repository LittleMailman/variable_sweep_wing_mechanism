# 可变后掠翼机构运动演示

本目录存放可变后掠翼机构的运动演示视频，用于展示驱动系统带动连杆机构运动，以及机翼后掠角增大和减小的过程。

## 运动与传动原理

机构采用**蜗杆作为传动输入构件**，通过轮系将运动传递至曲柄，再由曲柄带动连杆机构运动，实现机翼后掠角的变化。

**运动传递路径：**

`蜗杆输入 → 轮系传动 → 曲柄旋转 → 连杆机构运动 → 机翼后掠角变化`

演示采用的输入条件如下：

| 项目 | 说明 |
| --- | --- |
| 驱动输入构件 | 蜗杆 |
| 蜗杆转速 | **200 RPM**（转/分） |
| 传动方式 | 轮系驱动曲柄，曲柄带动连杆机构 |
| 演示内容 | 机翼后掠角增大与减小的运动过程 |

> **说明：** 200 RPM 指演示中设置的**蜗杆转速**，并非曲柄或机翼的转速。曲柄及机翼的实际运动速度与传动关系有关；视频仅用于机构运动展示，不代表已完成驱动效率、载荷或实物性能验证。
